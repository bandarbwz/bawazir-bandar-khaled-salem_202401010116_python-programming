# Week 12 – Computer Lab Monitoring

## Description

This Python program monitors the status of five computers in a computer lab.

The user enters the status of each computer:

- `A` = Available
- `U` = Used
- `M` = Maintenance

The program counts how many computers are available and displays the status of all five computers. The user can then choose whether to perform another monitoring cycle.

## Program Files

- `main.py` – Controls the main program and repeats the monitoring cycle.
- `check_computers.py` – Asks the user for the status of each computer.
- `count_available.py` – Counts the available computers.
- `display_status.py` – Displays the computer statuses and the number of available computers.
